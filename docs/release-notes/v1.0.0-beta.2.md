## PhotoPack Manager 1.0.0-beta.2 – Updates über GitHub

> **Testversion.** Bitte zunächst mit Kopien bzw. gesicherten Daten testen. Der Wiederherstellungsbereich schützt
> beim Verschieben, ersetzt aber keine Datensicherung.

### Neu
- **Automatische Updates (Installer-Version):** Beim Start wird auf GitHub nach einer neuen Version gesucht. Ein
  Update wird im Hintergrund geladen und beim Beenden installiert – oder sofort über „Jetzt neu starten“.
  Laufende Übertragungen werden dafür nie unterbrochen.
- **Portable EXE / ZIP:** Neue Versionen werden gemeldet, „Herunterladen“ öffnet die Release-Seite.
- **Einstellungen → Updates:** „Nach Updates suchen“; Suche beim Start abschaltbar (dann arbeitet das Programm
  vollständig offline).
- **Einstellungen → System → Grafikbeschleunigung:** abschaltbar bei Darstellungsfehlern einzelner Grafiktreiber,
  z. B. doppelt angezeigtem Mauszeiger. Wirkt nach einem Neustart.

### Behoben
- Paket-Taste direkt nach dem Wechsel der Schnellzuordnung nutzte auf langsamen Rechnern noch den alten Modus.

### Wechsel von beta.1
beta.1 hat noch keine Update-Funktion. Den Installer von beta.2 einfach über die vorhandene Installation
installieren (Daten bleiben erhalten), bei der portablen Version die EXE ersetzen.

### Downloads (Windows 10/11, 64 Bit)

| Datei | Zweck |
|---|---|
| `PhotoPack-Manager-1.0.0-beta.2-Setup.exe` | Installer – **empfohlen**, aktualisiert sich selbst |
| `PhotoPack-Manager-1.0.0-beta.2-portable.exe` | Ohne Installation; Daten im Ordner `PhotoPack-Daten` neben der EXE |
| `PhotoPack-Manager-1.0.0-beta.2-win-x64.zip` | Entpacken und `PhotoPack Manager.exe` starten |
| `SHA256SUMS.txt` | Prüfsummen (PowerShell: `Get-FileHash <Datei>`) |
| `latest.yml`, `*.blockmap` | Update-Informationen für die App (nicht zum Herunterladen gedacht) |

**Unsigniert:** Windows SmartScreen zeigt beim ersten Start „Der Computer wurde durch Windows geschützt“ →
„Weitere Informationen“ → „Trotzdem ausführen“.

### Was testen?
- Update-Weg: beta.2 installieren; sobald eine neuere Version erscheint, meldet die App sie selbst.
- Doppelter Mauszeiger: Einstellungen → System → Grafikbeschleunigung ausschalten → Neu starten. Bitte zurückmelden,
  ob der Fehler damit verschwindet.
- Abnahme-Prüfliste: [`AUDIT.md`](https://github.com/LiquidFlow-design/PhotoPack-Manager/blob/v1.0.0-beta.2/AUDIT.md#4-prüfliste-für-die-abnahme-auf-windows-1011).
  Rückmeldungen bitte über [**Issues → „Fehler melden“**](https://github.com/LiquidFlow-design/PhotoPack-Manager/issues/new/choose).

Alle Änderungen: [CHANGELOG](https://github.com/LiquidFlow-design/PhotoPack-Manager/blob/v1.0.0-beta.2/CHANGELOG.md) · Tests: [`TEST_REPORT.md`](https://github.com/LiquidFlow-design/PhotoPack-Manager/blob/v1.0.0-beta.2/TEST_REPORT.md)

### Bekannte Einschränkungen
- Keine Code-Signatur (SmartScreen-Hinweis, auch beim Installieren eines Updates).
- HEIC-Vorschau benötigt die „HEIF-Bilderweiterungen“ aus dem Microsoft Store.
- „Nur online“-Dateien aus Proton Drive/OneDrive werden beim Export heruntergeladen.
- Video-Wiedergabe abhängig vom Codec (H.264/VP9/AV1 ja; HEVC nur mit Hardware-Unterstützung).
